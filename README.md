# Autonomous Developer Intelligence & Security Watchdog

An autonomous, zero-cost intelligence pipeline that syncs with your GitHub repositories, parses package dependencies, aggregates tech feeds and security advisories, deduplicates stories using a consensus engine, evaluates relevance with Google Gemini, stores history in a local RAG vector store, and alerts you via Meta WhatsApp Cloud Sandbox.
